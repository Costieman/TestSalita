# Moving progress between desktop and phone

## Desktop to phone
1. Desktop: Settings → Download progress backup.
2. Send the JSON file to the phone.
3. Phone: Settings → Import progress backup.
4. Select the JSON file.

## Phone to desktop
Repeat the same process in reverse.

## Compatibility
- Raw Salita Quest v3.2 progress JSON
- Salita Quest v4.0 packaged backups
- Salita Quest v4.1 mobile backups and transfer codes

The app retains stable item IDs and unknown item records so later course versions do not discard previous learning history.


Version 4.2 adds daily quest and weekly-momentum fields. Older backups import normally; missing fields are initialized automatically without changing existing item mastery or SRS dates.
