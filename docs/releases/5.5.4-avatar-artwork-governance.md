# Salita Quest 5.5.4 — Avatar artwork governance

## Purpose

Release 5.5.4 establishes one canonical artwork registry for all 48 avatars. Collection cards, detail views, reward popups, profile menus, the desktop/mobile profile emblem and the in-course player avatar now resolve artwork from the same avatar ID.

## Root causes addressed

- Profile controls could retain the original catalogue object while later collection screens used the patched catalogue.
- Image repair could begin before the base avatar catalogue had loaded.
- Several screens assigned paths independently and therefore reacted differently to a failed or stale asset.
- The final eight rare animals depended on SVG wrappers that referenced a shared sprite as an external resource.
- Installed apps could retain pre-fix profile and artwork scripts.

## Runtime changes

`avatar-artwork-registry-v554.js` provides the canonical artwork registry. It:

- maps every catalogue ID to one packaged asset path;
- validates image decoding before assigning a source;
- retries through versioned local, ordinary local and repository-hosted sources;
- extracts the final eight animals directly from the packaged 512 × 256 sprite;
- binds images by stable avatar ID rather than by display location;
- repairs newly inserted avatar images through one observer;
- synchronizes the equipped avatar across all visible profile surfaces;
- provides a named placeholder only after all real artwork sources fail;
- exposes a 48-avatar audit through `verifyAll()`.

The profile loader now guarantees this order:

1. base catalogue;
2. canonical artwork registry;
3. catalogue hotfix and finalized model;
4. migration and collection/reward consumers.

`profile-app.js` waits for the finalized model before creating controls, preventing it from retaining a stale catalogue reference.

## Delivery

The installed-app cache advances to `salita-quest-v5-5-4-avatar-artwork-r47`. Both Tagalog and Bisaya loaders request the 5.5.4 profile runtime while retaining learner data and course progress.

## Validation

Run:

```bash
node scripts/validate-avatar-artwork-v554.mjs
node scripts/validate-avatar-progression-v550.mjs
```

The release gate checks all 48 canonical mappings, eight sprite crops, loader order, collection/profile/reward bindings, both language loaders and service-worker cache r47.
