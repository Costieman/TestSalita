# Salita Quest 5.5.0 — Avatar Progression

Release status: staged for validation; not yet merged or deployed.

## Overview

Salita Quest 5.5.0 replaces the former random weekly avatar-variant reward with a learner-controlled, account-wide collection of 48 Philippine-inspired avatars.

The release preserves existing learner profiles, course progress, XP, mastery, due dates, streaks, coins, keys, badges and previously earned avatar rewards.

## Avatar collection

- 48 stable avatar records across Starter, Common, Uncommon, Rare and Special rarities.
- Four equal-status starter choices: Anahaw, Waling-Waling Orchid, Jade Vine and Philippine Rafflesia.
- Full collection screen with locked greyscale artwork, 25/50/75% shard reveal and full-colour ownership.
- Any owned avatar can be equipped at any time.
- The equipped avatar is shared across Tagalog and Bisaya.

## Weekly rewards

- Completing all four Daily Quests earns one Daily Key.
- Six keys in a week open the weekly avatar reward.
- The learner chooses the target.
- No avatar is assigned randomly.
- Common avatars receive 100 shards per weekly reward.
- Uncommon avatars receive 50 shards per weekly reward.
- Rare avatars receive 25 shards per weekly reward.
- Reaching 100 shards unlocks the avatar and adds it to the animation queue.

## Level milestones

- Level 10: Narra
- Level 20: Nipa Palm
- Level 30: Katmon
- Level 40: Buri Palm
- Level 50: Parol
- Level 60: Banaba
- Level 70: Bangka
- Level 80: Medinilla Magnifica
- Level 90: Kulintang
- Level 99: Golden Salita Crest

Existing learners receive all milestone avatars for levels they have already reached. Milestone claims are account-wide and cannot be duplicated by switching courses.

## Unlock presentation and sharing

- Newly unlocked avatars receive a once-only reveal.
- The avatar can fly into its exact collection card.
- Reduced-motion and skip-animation paths are included.
- Badge, Badge Chest and Level Up cards use the learner's currently equipped avatar.

## Migration safety

`avatar-progression-migration-v1.js` performs an additive, idempotent migration before the new reward systems initialise.

The migration:

- preserves the existing equipped avatar;
- normalises older avatar aliases to stable catalogue IDs;
- merges Tagalog, legacy Tagalog and Cebuano key histories;
- converts old random reward IDs such as `eagle-sunrise` to the underlying avatar;
- preserves old `unlockedRewards` entries as owned avatars;
- converts old weekly claims into account-wide claims;
- never deletes or rewrites the original course-progress JSON;
- records migration completion and verification metadata on each learner profile.

## Offline release

The service-worker cache is now `salita-quest-v5-5-avatar-progression-r43`.

It pre-caches:

- all avatar progression runtime and style files;
- the full 48-avatar artwork catalogue;
- the Set 2 rare-animal sprite used by the final eight SVG entries;
- existing core application, profile, course and enhancement files.

Offline cache matching ignores query strings so staged `?v=` release parameters still resolve to the pre-cached file.
