# Salita Quest 5.5.7 — Complete Bisaya Audio

## Release status

This release connects the recorded Cebuano and British-English libraries to the released Bisaya course without changing learner progress, mastery, XP, rewards or stable item IDs.

## Audio coverage

The released Cebuano course contains:

- 182 course items;
- 177 unique Cebuano spoken texts selected through `example || term || root`;
- 176 unique English answers selected through `natural || meaning`.

Release 5.5.7 provides complete coverage for both sets:

- 356 `ceb-PH` manifest entries backed by 296 MP3 files;
- 337 total `en-GB` manifest entries, including 138 new Bisaya-specific MP3 files;
- zero required Cebuano texts missing;
- zero required English answers missing;
- zero manifest paths pointing to missing files.

Punctuation-equivalent Cebuano aliases may share one verified recording. The runtime does not substitute Tagalog pronunciation for Cebuano.

## Runtime route

Both pronunciation buttons and Hands-Free Review use the shared audio resolver:

```text
course text
→ staticAudioUrl(text, language)
→ audio/audio_manifest.json
→ same-origin MP3
```

Bisaya phrase playback requests `ceb-PH`. Hands-Free answers request `en-GB` after the five-second recall gap.

## Offline behavior

The service worker now:

- precaches `audio/audio_manifest.json`;
- uses cache-first delivery for same-origin audio files;
- stores each successful full MP3 response for later offline replay;
- supports browser byte-range requests from cached full recordings;
- advances the cache revision to `salita-quest-v5-5-7-complete-bisaya-audio-r49`.

Audio files are cached when played rather than forcing hundreds of downloads during first installation.

## Generation and recovery

Cebuano generation remains resumable through:

```bash
python3 scripts/generate_cebuano_google_audio.py
```

Missing Bisaya English answers can be generated without replacing the existing English library through:

```bash
python3 scripts/generate_missing_bisaya_english_audio.py
```

Neither generator stores Google Cloud credentials in the repository or browser application.

## Validation

`scripts/validate-bisaya-audio-library.mjs` verifies:

- complete released Cebuano and English coverage;
- valid and safe manifest paths;
- existing, non-empty MP3 files with recognised signatures;
- no unreferenced imported Cebuano or Bisaya-English recordings;
- correct `ceb-PH` and `en-GB` runtime routing;
- explicit prevention of Tagalog substitution;
- audio-manifest and cache-first service-worker integration;
- generator voice and text-selection consistency;
- execution from the Bisaya GitHub Actions workflow.

## Learner-state safety

This release does not alter:

- progress storage keys;
- stable course item IDs;
- mastery or due-date calculations;
- XP, coins, streaks or daily keys;
- avatars, badges or reward ownership;
- JSON backup/import or transfer codes.
