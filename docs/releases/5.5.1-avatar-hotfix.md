# Salita Quest 5.5.1 — Avatar Progression visual and reward hotfix

This patch addresses the first live browser feedback after the 5.5.0 Avatar Progression release.

## Fixed artwork

- Repairs the Common and Uncommon plant artwork that could appear as broken images in the collection and reward reveal.
- Reconstructs the final eight rare-animal avatars from their source sprite so they render as ordinary browser images rather than blank externally referenced SVGs.
- Uses the same resolved artwork for collection cards, profile controls, reward reveals and achievement sharing.

## Fixed collection layout

- Prevents long avatar names from widening an individual grid column.
- Keeps every card within a stable responsive grid.
- Allows avatar names to wrap over two lines rather than clipping neighbouring cards.

## Collections navigation

The former standalone **Badges** sidebar destination is now **Collections**. It opens a choice between:

- **Badges** — achievements and the Badge Chest;
- **Avatars** — the 48-avatar account-wide collection.

The direct Avatar Collection shortcut remains in the learner profile menu.

## Starter avatars

Anahaw, Waling-Waling Orchid, Jade Vine and Philippine Rafflesia remain the four equal-status onboarding choices. They are also treated as Common weekly targets:

- each can be collected after six Daily Keys;
- each awards 100 shards in one weekly reward;
- each appears in both the Starter and Common collection groups;
- selecting one during onboarding continues to grant ownership immediately.

## Level milestone safety

The milestone runtime now waits until the final Level 99 progression system is installed before reading the learner's level. It also repairs any Level 10–99 avatar claims that were created above the learner's real level by the initial 5.5.0 race condition.

The repair removes only unsupported future milestone claims and their pending animations. It preserves avatars that were legitimately unlocked through weekly shards or are currently equipped.

Placement remains content-access only and does not award XP, levels or milestone avatars.

## Unlock reveal safety

Unlock acknowledgement is now saved before the collection-flight animation starts. Duplicate pending entries for the same reward are consumed together, and a finishing lock prevents the same reveal from reopening while the animation is still running.

## Offline release

Service-worker cache:

`salita-quest-v5-5-1-avatar-hotfix-r44`

The hotfix runtime and styles are included in offline installation. Existing `5.5.0` caches are replaced when the updated service worker activates.
