# Salita Quest 5.5.6 — Canonical Avatar Runtime

Status: merged into `main` on 1 August 2026 through PR #42. The merge commit is `498ab45642457fd2ada494b62bcc2bfa6daa6139`.

## Artwork architecture

- The app catalogue points to 48 direct canonical PNGs under `avatars/canonical/`.
- One canonical manifest records the stable IDs, aliases and paths.
- The shared artwork resolver reads image paths from the catalogue instead of maintaining another path registry.
- There is no runtime sprite extraction.
- There is no canvas artwork conversion.
- There is no raw GitHub artwork fallback.
- There is no document-wide avatar image source observer or source-rewrite pass.
- Missing artwork uses one bounded, local initials placeholder without changing saved avatar state.

## App integration

The same canonical path is used by profile emblems, the collection screen, details, weekly rewards, level rewards, unlock celebrations and avatar-aware sharing. Tagalog and Bisaya continue to use the same account-wide avatar identity and artwork runtime.

The service worker cache is `salita-quest-v5-5-6-canonical-avatars-r48`. It precaches the manifest and all 48 canonical PNG files and no longer precaches the legacy sprite, SVG or WebP artwork set.

## Learner state preservation

The update preserves existing stable avatar IDs and historical aliases. Validation covers equipped identity, owned avatars, shard totals, queued unlocks and claimed level rewards. Existing course progress, XP, coins, streaks and profile data are not cleared or manufactured by this artwork update.

The mobile refresh page removes app caches and service-worker registrations only. It does not clear learner local storage.

## Validation

The repository validator checks all 48 PNG signatures, 512 × 512 dimensions, alpha channels, unique canonical paths, consumer bindings, service-worker coverage, JavaScript syntax and prohibited legacy mechanisms.

Before merge, the canonical mapping suite passed 1,044 checks, the runtime architecture suite passed 194 checks and both the Avatar Progression and full Bisaya regression workflows passed. Desktop, mobile and installed-PWA visual checks remain useful after deployment.
